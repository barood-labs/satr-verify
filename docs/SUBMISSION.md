Satr Verify is a bilingual Arabic and English paperwork checklist for people new to the United States, and the closed loop that checks it. A newcomer picks a task, such as a state ID, a bank account, or a clinic, and sees the documents and the order. A Cursor cloud agent built the page and satr-verify. Kane CLI runs the plain-English flows in a real browser and writes a report the agent acts on. The search flow was committed before a search box existed. Kane returned result 740: no Search tasks field. The agent read the report, added the field, and left the flow alone. The same flow then passed, result 100, in English and Arabic. The app is at https://barood-labs.github.io/satr-verify/.
